# 支票簽收表單

這個專案包含一個支票簽收表單的單頁應用程式，適合在 iPad 或手機上直接使用。

## 功能特色

- 輸入支票日期與金額
- 填寫支票收款人（廠商名稱）
- 提供兩個簽名欄位，可直接在螢幕上簽名
- 設定簽名日期，自動鎖定已簽名欄位
- 表單確認後會鎖定避免修改

## PWA 使用方式

本專案支援 Progressive Web App (PWA)，可安裝到桌面離線使用。

1. 透過瀏覽器開啟 `index.html` 或部署的網頁。
2. 在瀏覽器選單中選取「加入主畫面」或類似選項。
3. 完成後會在桌面看到圖示，可像應用程式一樣使用。

## 部署到 GitHub Pages

1. 將所有檔案上傳到 GitHub 儲存庫根目錄。
2. 在 GitHub 專案頁面的 **Settings → Pages** 內，選擇 `main` 分支，並設定根目錄為 `/`。
3. 儲存設定後，稍待片刻即可透過 `https://<your-username>.github.io/<repository-name>/` 來查看及安裝應用程式。
